# Rubik Camera Solver

เว็บแอปแก้รูบิค 3×3 ภาษาไทย ทำงานในเบราว์เซอร์ทั้งหมด ไม่ส่งรูปไปที่ไหน

## 2 ทางเลือก
1. **ใช้กล้องสแกน** – ถ่ายทีละด้าน (F, R, B, L, U, D) แอปอ่านสี แล้วให้ตรวจแก้ก่อนคำนวณ
2. **ตั้งสีเองบนโมเดล 3 มิติ** – เลือกสี แล้วแตะแต่ละช่อง ลากหมุนโมเดลได้ มีแผ่นคลี่ให้แก้ด้วย

จากนั้นแอปตรวจความถูกต้องของลูก (สีครบ 9 ช่อง/สี, บิดมุม/ขอบ, parity) และแสดงวิธีแก้ทีละตา (~20 ตา)

## ใช้งาน
เปิดผ่าน GitHub Pages (ต้องเป็น https เพื่อใช้กล้อง) หรือรันในเครื่อง:

    python3 -m http.server 8000   # แล้วเปิด http://localhost:8000

ทดสอบ: `python3 test/e2e.py` (ต้องมี playwright + Chrome)

## เทคนิค
- ตัวแก้: [cubejs](https://github.com/ldez/cubejs) (MIT) – Kociemba two-phase, รันใน Web Worker
- แยกสี: Lab + median 3×3 + Hungarian assignment บังคับสีละ 9 ช่อง ใช้ศูนย์กลางเป็นตัวอ้างอิง จึงใช้ได้กับรูบิคทุกชุดสี
- ทำงานออฟไลน์ได้หลังโหลดหน้า (ฟอนต์ไทยดึงจาก Google Fonts ถ้ามีเน็ต)
